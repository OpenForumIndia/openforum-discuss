Lazy CLI Tools List (with GitHub Repositories)

1. lazygit
   Terminal UI for Git repositories.
   GitHub: https://github.com/jesseduffield/lazygit

2. lazydocker
   Terminal UI for managing Docker containers, images, volumes, and logs.
   GitHub: https://github.com/jesseduffield/lazydocker

3. lazyjournal
   Terminal UI for viewing and filtering systemd journal logs.
   GitHub: https://github.com/Lifailon/lazyjournal

4. lazysql
   Cross-platform terminal database manager.
   GitHub: https://github.com/jorgerojas26/lazysql

5. lazymake
   Interactive terminal interface for Makefiles.
   GitHub: https://github.com/rshelekhov/lazymake

6. lazyvim
   Modern Neovim configuration framework.
   GitHub: https://github.com/LazyVim/LazyVim

7. lazyjj
   Terminal UI for the Jujutsu version control system.
   GitHub: https://github.com/Cretezy/lazyjj

8. lazycontainer
   Terminal UI for managing containers.
   GitHub: https://github.com/ssleert/lazycontainer

9. lazycli
   Framework for building interactive CLI apps.
   GitHub: https://github.com/jesseduffield/lazycli

10. lazyssh
    SSH connection/session manager.
    GitHub: https://github.com/moul/sshportal

11. lazynpm
    Terminal UI for managing npm packages.
    GitHub: https://github.com/jesseduffield/lazynpm

12. lazydocker-compose tools
    Tools for managing Docker Compose stacks interactively.
    GitHub: https://github.com/docker/compose

13. lazykube
    Lazykube is a lightweight tool for simplifying Kubernetes management.
    GitHub: https://github.com/TNK-Studio/lazykube

14. lazygit-playground tools
    Experimental tools around lazygit workflows.
    GitHub: https://github.com/jesseduffield/lazygit
